# تبدیل تصاویر به WebP

## تصاویر جدید
هنگام آپلود (تصاویر مستندات پژوهشی، تصویر شاخص و تصاویر داخل متن مقالات/وبلاگ فعالیت‌ها) تصویر
خودکار به WebP تبدیل می‌شود (کیفیت ۸۲، حداکثر ضلع ۲۵۶۰px). تصاویر متحرک (GIF) و WebP ثابت دست‌نخورده می‌مانند.
تنظیمات در `.env`: `IMAGE_WEBP_ON_UPLOAD` (پیش‌فرض true)، `IMAGE_WEBP_QUALITY`، `IMAGE_MAX_SIDE`.
اگر سرور ضعیف است و آپلود کند شد، مقدار `IMAGE_WEBP_ON_UPLOAD=false` بگذارید و هر چند وقت یک‌بار اسکریپت زیر را اجرا کنید.

## تصاویر قبلی — `scripts/convert_images_to_webp.py`
فقط به Pillow و SQLite نیاز دارد (مستقل از Flask). از ریشه‌ی پروژه (ترجیحاً با توقف موقت برنامه):

```bash
python scripts/convert_images_to_webp.py scan                    # فقط گزارش، بدون تغییر
python scripts/convert_images_to_webp.py convert                 # پشتیبان + تبدیل + به‌روزرسانی دیتابیس
# سایت را بررسی کنید؛ سپس:
python scripts/convert_images_to_webp.py finalize --run backups/webp_migration_<زمان>
```
- `convert` اصلی‌ها را حذف نمی‌کند. قبل از هر کار، `db_before.sqlite` (نسخه‌ی کامل دیتابیس) و کپی همه‌ی
  فایل‌های اصلی در `backups/webp_migration_<زمان>/` ساخته می‌شود. دیتابیس در یک تراکنش به‌روز می‌شود و اگر
  ارجاعی به فایل ناموجود ایجاد شود، همه‌چیز برگردانده می‌شود.
- `finalize` پس از بازبررسی (فایل جدید معتبر، ارجاع دیتابیس، کپی پشتیبان) اصلی‌ها را از `uploads/` حذف می‌کند؛
  کپی آن‌ها در پوشه‌ی پشتیبان می‌ماند.
- اجرای مجدد امن است؛ فایل‌های webp، تصاویر متحرک، خراب/ناموجود و مواردی که WebP‌شان بزرگ‌تر می‌شود تبدیل نمی‌شوند
  و در گزارش می‌آیند.
- گزینه‌های `--db`، `--research-dir`، `--articles-dir`، `--backup-dir`، `--quality`، `--max-side`.

### بازگردانی
```bash
python scripts/convert_images_to_webp.py rollback --run backups/webp_migration_<زمان>
```
فایل‌های اصلی را (در صورت نیاز از پشتیبان) برمی‌گرداند، ارجاع‌های دیتابیس را به حالت قبل می‌برد و webpهای
جدید را پاک می‌کند. بازگردانی کامل دستی: برنامه را متوقف کنید و `db_before.sqlite` را جای فایل دیتابیس بگذارید
و پوشه‌ی `files/` را به `uploads/` برگردانید.
